# DiPlay v0.3.15 — 车机桌面常驻Dock栏挤压黑边自动防御与前台置顶恢复

## 更新

- **全生命周期车机桌面 Dock 栏挤压黑边自动防御**（Issue #363）：
  - 突破此前 3 秒 settle 窗口限制，在会话运行的任意时刻智能识别车机系统/桌面 Dock 栏弹出引起的视窗高度收缩特征；
  - 拒绝将视频图层错误收缩至挤压尺寸，始终维持既定的满屏基准渲染，杜绝画面两侧反复出现黑边锁定。
- **实验性功能：桌面 Dock 栏挤压自动置顶消除（Re-front Task）**（Issue #363）：
  - 新增「置顶消除 Dock 栏（实验性）」设置项（默认关闭）；
  - 检测到视窗被挤压时，自动通过前台任务重排（`REORDER_TO_FRONT`）拉起当前 CarPlay 任务，无需返回桌面即可瞬间迫使系统 Dock 栏隐藏退出，恢复完整沉浸视窗；
  - 包含每次事件最多 3 次尝试、5 秒间隔递增退避机制，Dock 栏消除恢复高度后自动复位。

- 完整单元测试全部通过，发布包内嵌源码 commit 严格核验通过。
