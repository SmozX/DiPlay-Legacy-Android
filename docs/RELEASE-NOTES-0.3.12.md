# DiPlay v0.3.12 — 热点启动失败无线电重载自愈、修复驱动AP残留与重试绑定死锁

## 更新

- **热点启动失败清理引入无线电重载自愈，消除驱动残留死锁**（Issue #330, #348）：
  - 针对本田思域等车型实测确认：hostapd 启动失败后仅终止守护进程不足以清除内核网卡驱动中的 AP 模式残留状态，导致后续再次尝试绑定仍然失败，此前必须整机重启才能恢复；
  - 启动失败清理路径现改为在终止进程并清理临时文件后，自动执行一次无线电重载循环（关闭 Wi-Fi -> 延时 1 秒防抖 -> 重新开启 Wi-Fi），重置底层驱动运行时状态并保持就绪，彻底解决下一次热点重试无法绑定的困境。
- **内存屏障与状态变量注解位置整理**（Issue #330, #348）：
  - 修正 `@Volatile` 变量注解与 `touchedSystem` 声明的对应关系，确保多线程状态检查符合规范。

- 版本 `0.3.12` / `versionCode 132`，包名 `com.shihab.diplay`，最低 Android 4.2（API 17）。
